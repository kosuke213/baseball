# 選手ID付き遷移の仕様とルール制限

## 状態と参加者

`Frame` は不変のdataclassです。2球団各9人の打順、現在の打順位置、各球団の投手、塁上の `RunnerToken`、アウト、回・表裏、得点、カウントを保持します。投手と打者の同一人物起用は状態表現上は可能ですが、二刀流の位置変更・再登板の処理は対象外です。

`RunnerToken` は選手ID、責任投手ID、自動走者か、通常の自責候補かを保持。自責点の公式計算そのものは行いません。投手交代後も既存走者の責任投手を保持し、代走では選手IDだけを入れ替えます。

`Move` は選手ID、開始位置（打者0／一〜三塁1〜3）、終点を持ちます。終点は塁1〜3、得点 `H`、アウト `OUT`、第3アウト後の残塁 `LOB`。元のLOB欄でIDだけ分かる場合、最終塁を推測しません。

全参加者に必ず一つの終点を要求します。得点者、アウト者、塁上の選手、残塁者、サヨナラにより打ち切られた選手を合わせると、元の参加者集合と一致しなければ例外になります。塁の重複、理由のない消失、逆走、後方走者による生存中の先行走者の追い越しを拒否します。複数人が得点する場合、同一プレー内の詳細時刻を捏造せず、先行走者を先に処理します。

## 原本由来の経路

第6段階の観測打席の窓と同じ範囲を読みます。`run_b`・`run1..3` の得点者、進塁後のID、残塁IDを照合して各参加者の行き先を復元。残りがアウト増分と一致した場合のみアウト者とします。同一プレー内のアウト順序や詳細な経由塁は、これだけでは確定しません。

元のIDを「打者B、窓の開始時の一塁走者1、二塁走者2、三塁走者3」の役割へ変換します。窓途中の盗塁等があれば、各プレーにおける現在位置も保持。抽選した経路を現在の架空選手IDへ当てはめます。経験的経路の `source_ref` はテンプレートのSHA256で、`identity_model.json` の `sources` から具体的な原本範囲へ戻れます。

途中の代走・打者投手の変更等を現在の窓復元器で追えない場合は除外します。原本自体に情報が存在しないと断定するものではなく、NPやラインアップ等との結合で改善できる余地があります。

## 確率とルールの分離

確率層 `CalibratedModel` は窓結果と進塁経路を選択します。ルール層 `validate_plan`・`apply_plan` が参加者の整合性、進塁、得点、アウト、打順、終了条件を検査・適用します。ルールは確率を都合よく再抽選しません。

APIの標準は経験的経路のみ。`allow_assumptions=True` を明示した評価モードでは、経験件数に10件相当の保守的進塁を加えます。同じ開始状態・結果・通常／延長の経路がなければ、同じ状態・結果の他方の区分へ戻ります。仮定の一塁打は1塁分、二塁打は2塁分、三塁打は3塁分、通常アウト・三振は打者をアウトとして走者を保持するなど、明示した限定経路です。失策出塁の仮定は強制進塁相当で、自責点は不明とします。

未観測の走者のみの終了や「その他打席」に、勝手な走者選択の仮定を置きません。経路がなければ例外。経験的経路と仮定は、イベントの `source` で区別します。評価のIDモデルは仮定を明示したモードであり、標準の経験的経路限定モードと同一分布ではありません。

## 支持する処理

| 処理 | 範囲 |
|---|---|
| 安打・本塁打 | 打者が記録に対応する塁以上へ到達、全参加者の進塁を追跡。本塁打は全員得点、アウト0 |
| 四球・死球・妨害 | 単純な一塁付与と必要な強制進塁。満塁の押し出しを含む |
| 三振 | 通常は打者アウト。復元した振り逃げは一塁空きまたは二死の条件を検査 |
| 犠打・犠飛 | 二死未満、走者あり、打者アウトの経路。犠飛は走者の得点を要求 |
| 野選・その他アウト | 野選は先行走者を必要とする。その他アウトは打者とは限らないアウト者を保持 |
| 併殺 | 明示的な基本併殺は一塁走者と打者をアウト。経験的な複数アウトもIDを保持 |
| 盗塁・走塁死等 | 経験的途中プレー、または `runner_event` で対象走者を明示。打席未完了の第3アウトでは打順を進めない |
| カウント | `count_event` は外部から与えたボール・ストライク・ファウルを処理。投球確率は推定しない |
| 攻守交代・延長 | 3アウトで攻撃停止、`advance_half` で交代。延長の自動走者は前の打順の選手、自責候補外 |
| サヨナラ | 通常は勝利点まで、本塁打は全員の得点を数える。残りの未処理得点者は `halted_ids` に記録 |
| 代打・代走・投手交代 | カウント開始前の限定処理。再出場を防止し、代走・投手交代でも既存走者の責任投手を保持 |

## 明示的に非対応の処理

同一プレー内の第3アウトと得点タイミング、フォースやアピール・第4アウトの判定、打球後に打者が余分な塁を狙ってアウトになった経路、打者が生きた犠打犠飛、一塁付与と同時の追加進塁やアウト、途中の交代を含む原本窓の完全な復元を対象外にしています。原本でIDを復元できても、これらはルール対応とは別です。

サヨナラ安打の公式な安打種類の短縮、正しい全RBI、全自責点、勝敗投手・セーブ、継投の最低対戦打者、守備位置・登録資格、途中カウントからの交代時の公式責任、二刀流の位置変更、自動走者に前打順の投手が該当する例外、正式な引き分け規則は対象外です。攻撃回数上限に達した同点試合を勝手に公式引き分けにせず例外を返します。

各イベントの `official_scoring_complete` はfalseです。IDと得点を追跡できることを、すべての公式記録が正しいことと同義にはしていません。
