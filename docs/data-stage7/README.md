## 2. 予測精度と校正

「10%と予測した出来事が、およそ10%起きるか」を確かめるのが校正です。温度スケーリング、リーグ平均との混合、両者の組合せ、補正なしの4方式を比較しました。温度10候補・混合比率7候補の計88候補行を保存しています。各方式の係数は2024年前半だけで決め、後半は方式の選択に使いました。候補範囲外・別の校正法まで無効だと示したものではありません。

| 用途 | 基礎モデルの学習 | 校正の学習／評価 | 規模 |
|---|---|---|---:|
| 校正係数の推定 | 2023年 | 2024年前半で推定 | 1,261試合・94,570打席 |
| 方式の選択 | 同じ2023年モデル | 2024年後半で比較 | 1,167試合・87,809打席 |
| 公開モデルの参考評価 | 2023〜2024年で再推定 | 校正係数を固定し2025年へ適用 | 2,430試合・182,926打席 |

7月1日をまたぐ再開試合は、試合内イベント日付の最小・最大で識別し、70窓を前半・後半の双方から除外しました。校正学習と方式選択の試合は重なりません。ただし第6段階で2024年・2025年を既に利用しているため、**2024年の再分割は探索的検証、2025年は既知の参考期間です。独立した未使用の最終テストはありません。** 新規期間の大量取得は行っていません。

4方式すべてが前半の学習で温度1・混合比率0を選びました。後半で対数損失を比較し、Brier・最大確率ECEの悪化を抑える選択規則でも、補正なしが残りました。2025年に合わせた係数変更はしていません。

各指標は小さいほど良好です。Brierは14分類の二乗誤差の合計、最大確率ECEは10等幅ビン、クラス平均ECEは14分類の平均です。

## 3. 個別走者の追跡

`Frame` に打順・現在打者・投手・塁上の選手IDを保持します。`RunnerToken` は出塁時の責任投手と自動走者の区別も保持。結果には得点者・アウト者・残塁者・サヨナラで打ち切った選手を返します。全参加者の行き先が一つずつあることを確認し、選手の消失・重複を拒否します。

配布ZIPを独立フォルダーに展開し、追加ライブラリを読み込まない `python -S example.py --model-dir . --journal example.jsonl` でも実行しました。シード726の一死一・二塁から二塁打の例では、**R2とR1が得点し、打者Bが二塁へ到達**。経路は原本由来で、責任投手HPも保持されました。同じシードの再実行と、保存イベントの再生で同じ状態になりました。[検証記録](verification.json)

確率への実在選手IDと、試合内の架空選手IDは別です。架空IDを勝手に実在選手へ対応付けません。`batter_model_id`・`pitcher_model_id` を明示しなければ、リーグ・条件の基礎分布を使います。例えば一死一・二塁、左打者対右投手、初回表・同点・個人IDなしでは、単打12.979%、二塁打4.442%、四球8.084%、三振23.065%です。

## 5. 実測由来と仮定

経験的経路は原本の参加者の終点から復元します。同一プレー内の詳細な経由塁・時刻・アウト順序まで分かったとは扱いません。残塁IDだけが分かる場合は最終塁を捏造しません。APIの標準は経験的経路だけを利用し、経路がなければ `UnsupportedRule` で停止します。

`allow_assumptions=True` を明示した場合のみ、経験件数に10件相当の保守的な固定進塁を加えます。仮定では単打1塁分・二塁打2塁分などとし、経験的経路とは `plan.source` で区別します。出所は `empirical`・`assumption`・`explicit_event` の3種です。同じ開始状態・結果の通常／延長区分がなければ他方の経験的経路に戻る処理も明記しています。未観測の走者だけの終了に適当なアウト選手を割り当てることはしません。

## 8. 統合前の重大な残課題

1. 未観測・未対応の経路に正の結果確率が残り、半イニングや試合の完走を保証できない。失敗の引き直しによる回避は禁止。
2. 第3アウトと得点のタイミング、複雑な交代・走塁死、公式記録の未対応。IDを保存できることと、全成績が公式に正しいことは別。
3. 状態・得点予測は単純モデルより悪い。校正の全体補正も効かず、犠打・犠飛等の偏りと少数条件の不確実性が残る。
4. 新しい独立評価期間がない。2025年へ繰り返し合わせて性能を主張しない。
5. 架空の潜在能力を実データの確率へ結び付ける関数、疲労・球場・戦術、長期成長は別途設計・検証が必要。

## 10. 今後追加すべきデータ・処理

まず既存原本を活用します。交代・NP・ラインアップとの結合、打者の伸塁アウト、第3アウトのフォース／時系列、公式記録用のプレー記述を詳しく解析する余地があります。原本不足と、現在の復元器の未対応を区別してください。

追加取得を優先するのは、利用条件を確認した**未使用の評価期間**と、既存原本で決着しない詳細プレー情報です。犠打・犠飛や稀な走塁は、まず状況・戦術の条件と件数を確認します。公式戦の球速・回転・打球角度が必要な物理モデルは、実測データを適法に確保する別課題です。NPB等への対象拡大も、定義・環境の違いを検証する必要があります。

CatBoost等の本格学習は今回行っていません。第8段階ではまずルールの未対応・記録契約・独立評価を整えます。その後、状況により異なる犠牲打等の偏りを改善する候補として、軽量なモデルと比較する価値があります。現時点で複雑なモデルへの全面置換を推奨する根拠はありません。

出典・利用条件は [ATTRIBUTIONS.md](../../data_sources/stage7/ATTRIBUTIONS.md)、詳細な数値は [公開データフォルダー](../../data_sources/stage7) に保存しています。
