研究は合計 **3資料・856項目** です。研究内でIDがある参加者は計72人（56＋16）。打撃実験の16人には個人別データがないため、架空の参加者IDを追加していません。

単位を確認してm/sへ換算できた速度データは、打撃実験の **全体平均4項目** です。例えば低い球への打球速度は平均151.4km/h・SD9.8km/h、高い球への打球速度は平均148.7km/h・SD12.1km/h。これをプロ野球の全打球の分布とは扱いません。Table 1のN=39〜41と、本文の反復試行の平均化の記述からは、Nの集計単位を一意に確認できません。16人とは別の人数や、独立な打球数として解釈しないよう保存しました。

原本にない年齢・体重、単位、個別打球、投球速度、参加者の国籍を埋めていません。研究の匿名IDとプロ選手IDを氏名などから対応付けていません。

## 未取得のものと理由

- **MLB / Baseball Savant / StatsAPIの大量取得**：MLBのTerms of Useで自動スクリプト収集の禁止を確認。再利用可能なゲーム用DBの許諾を確認できないため、センサーデータを取得していません。解析ライブラリのライセンスやミラーの公開だけで原データの許諾があるとは判断していません。
- **OpenBiomechanics**：データはCC BY-NC-SAと追加の利用除外条件。コードのMITとは別で、将来の営利利用を含む本プロジェクトへ共通基盤として組み込んでいません。
- **台湾プロ野球TrackMan、COR別打球速度、VICON投球データ**：関連Zenodoレコードは制限公開。ファイルや再利用条件を確認できず未取得です。
- **台湾CSVの球速単位**：対応論文のDOIは確認しましたが、出版社への接続は利用不可、PMC本文は人による確認が必要な画面でした。単位確認は未完です。
- **Figshare**：APIホスト `api.figshare.com` を環境設定の保存済みドラフトへ追加しましたが、現在の実行環境へ反映・Publishされておらず接続できませんでした。取得済みとは扱っていません。

個別のURL・確認結果・確認できた文書の指紋は [source_review.json](../../data_sources/stage5/source_review.json) に記録しました。公開資料の条件確認と取得は実施済みですが、追加の契約やアクセス申請、提供元への連絡はしていません。

## 検査と復元

既存分を含む **89テストが合格**。実データでは、追加11,983試合のイニング別得点と最終得点の照合が全件合格し、SQLite整合性・外部キー検査も合格しました。これは記録同士の整合性を確認する検査で、独立情報による正確性や、シミュレーションの再現精度の保証ではありません。

- CC BYの明示・公開状態・DOI版・元ファイル名・著者のMD5を確認し、別途SHA256を固定。
- 確認資料が取得できない場合は依存データを取得しない。制限公開・非商用ライセンス・異なるファイルは受け付けない。
- 球速の単位不明値は換算せず、個人測定、個人の平均、全体平均、相関を区別。
- 原本の指紋と転記の対応、元の表セル、出典行、Nの意味を保持。
- スナップショットの再利用・破損検出・失敗後の前版維持・中断後の再開を検査。

取得原本は **44ファイル、計94,762,789バイト**。DBとは別の原本バックアップZIPに、過去の段階を含めて全44件を保存しました。未使用の177列を含む年別プレーZIP、人物表の全16分割、今回の研究CSV・DOCX・PDF、利用条件確認資料を保管しています。第1段階に調査した候補をすべて取得したという意味ではありません。

配布DBには研究の原本も同梱し、全原本のバックアップは別ZIPにしました。DBの確認だけなら最初のZIPで足ります。DB・全原本それぞれのサイズとSHA256は [bundle.json](../../data_sources/stage5/bundle.json)、原本の取得URL・日時・条件は [manifest.json](../../data_sources/stage5/manifest.json) で確認できます。

配布用の原本バックアップと前段階の配布DBを新しいフォルダーへ展開し、**ネット要求0件で再構築して、同じ第5段階DBのSHA256になることを確認しました**。全44原本の指紋も一致。以前の全570,548プレー行と7,289試合の検査行をそれぞれ順に比較し、変更がないことを確認しています。現行スナップショットは `3380cf3ee94809d4dae3fe92`、DB SHA256は `64c9ed903efa996ecc00fcbba6388f1cec9a79fb7b4a9b3ea195ae6868b19125` です。

収集計画・版固定・復元方法は [利用手順](../../data_sources/stage5/README.md) を参照してください。定期収集や新しい版への自動切り替え、モデル学習は有効にしていません。
