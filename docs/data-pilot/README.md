## 少量検査で判明したこと

**年の試合数を2,430と決め打ちしない。** 実ファイルは2,429行でした。予定数を基に架空の1試合を補わず、実収録範囲2024-03-20〜09-30と件数をそのまま記録しました。日程や中止の別の一次資料との突き合わせは次段階です。

**日付だけでは試合を結べない。** 同日ダブルヘッダーを8試合、延長を8試合、中断後の再開を3試合含めました。分類には重なりがあります。再開試合では同じgame_id内に複数の日付が実在します。例えばBOS202406260には6月26日と8月26日の行がありました。原記録の日付を1日に上書きしていません。選択した32試合と理由は [sample_games.csv](../../data_sources/pilot/sample_games.csv) にあります。

**空欄の数と品質不良の数は違う。** プレーの投球列の空欄13行はすべて元イベントが`NP`でした。塁に走者がいない空欄、守備機会のない空欄、気象の観測・現象を表す記号は分けて扱う必要があります。気温24時刻に空欄はなくても、天気・雲量・視程はそれぞれ17行が空欄です。列ごとの空欄数・記号を [quality.json](../../data_sources/pilot/quality.json) に残しました。記号の数値化や補間はしていません。

**IDはよく結べても、全ての情報源が結べるわけではない。** 今回の打者・投手593件はkey_retroで一意に一致し、未対応・複数候補0件でした。採用693人のうちMLBAM IDの空欄は55件、NPB IDがあるのは129件です。追加の100例を含んだ集計なので、MLB選手全体の欠損率ではありません。日本のボードには外部ID・行単位の出典・verified列がなく、氏名や著者の注記だけで自動統合できません。球速等も公式の計測値として一括学習する対象にしていません。

## どこまで検査したか

- 5データセットの件数、全列の空欄・元記号、行の重複、主キーの重複・欠損。今回、主キーの欠損・重複は全て0。
- 全2,429試合のイニング別得点合計と最終スコア。
- 32試合のプレー順、初期状態、攻撃チーム、回、得点推移2,580区間、アウト範囲、同一攻撃内のアウト・塁占有2,010区間、攻守交代570区間、最終スコア・総アウト数。
- SQLiteのintegrity_checkとforeign_key_check。破損原本・取得失敗・不一致は成功として隠さない仕組み。
- 通信なしの再実行で原本のSHA256を全件再検査し、同じDBの行と集計を再構築すること。

これは**同じ提供元の加工済みCSVと試合別記録との内部整合性の検査**です。原スコアカードとの独立照合、Retrosheetイベント文法の完全再実装、全ての走者交代・自動走者の規則検査はしていません。Statcastの球速・回転・打球計測の本体はまだ取得していません。気象データも今回のMLB32試合に結んでいません。標本は境界条件を試すための意図的な選択で、無作為な評価用標本ではありません。

## 今回取得しなかった本体

| 対象 | 理由と次の扱い |
|---|---|
| MLB Stats API / Savant / 二次rawアーカイブ | 一次提供元の自動取得・学習・再配布条件が未解決。コードのOSSライセンスをデータの許可と扱わない |
| NPB公式の統計・公示等 | 二次利用・無断転載の表示があり、用途別の条件確認・許諾が先 |
| OpenBiomechanics | 非商用・継承と追加の利用者条件があり、採用を保留 |
| Meteostat Bulk | 現行資料は年別Parquetと変数別_source、モデル補完を案内。旧観測所年別CSVの想定で要求せず、小分け取得を後で確認 |

原本のHTTP失敗は最終取得では0件でした。初回は選手ID表16ファイルが3 MBの上限にかかり、本体をダウンロードする前に停止しました。実サイズを確認し、参照表に必要な分割を取得できる5.5 MB/ファイル・全体96 MB以内へ調整して再実施しました。[この記録](../../data_sources/pilot/initial_size_guard.json) と、条件確認による保留は別に残しています。
