# 第11段階：架空選手の能力・成長・疲労・故障と長期キャリア

**選手ごとの能力が打席確率に影響し、出場による疲労・故障、休養・復帰、年次の成長・衰退を、同じ選手IDのまま引き継げるようになりました。** 選手の能力が高くても結果を保証せず、潜在才能も将来の到達値や成績を予約しません。

能力付き独立検証は**1,000試合すべて完走**。実際のキャリアをつなぐ試験も**12球団・各143試合×2シーズン＝1,716試合を完走**しました。試合とキャリアの再生は一致し、成績整合性エラー・優先記録未確定・出場不可／未来状態の起用は0件です。

この実験基盤では、第12段階の有限な新人獲得・球団編成・選手の入れ替わりへ進めます。能力・成長・健康の係数はゲーム上の仮定で、本物のNPBや医学に校正された予測モデルではありません。

## 1. 何ができるか

- 長打・選球眼・三振回避などの違いが、対戦投手の能力と組み合わさって確率を変えます。
- 疲労した選手の実効能力は下がり、出場負荷から翌日以降の状態が変化します。欠場・リハビリ中は起用しません。
- 潜在特徴、年齢、経験、育成環境、健康と抽選に応じて、成長・停滞・衰退が起こります。よい打率だから必ず成長する処理はありません。
- 原本の確率と、架空選手の能力・健康に導入した仮定を分けます。
- 公開APIの評価は真の内部能力とは別です。内部才能や将来の乱数状態を返しません。

公開データの実例として、**林 翔太**（T07）の長打評価は82点です。これは誤差付き評価で、真値・将来の上限・将来の本塁打数ではありません。健康状態や役割も公開データから確認できます。

## 3. 能力が結果へ影響するか

同じ無走者・無死の状況で、各条件100,000打席、計800,000打席を抽選しました。打席完了を条件にした独立な確率検証で、80万試合ではありません。能力+1は内部尺度の1単位で、全ての係数はゲーム上の仮定です。

| 条件 | 本塁打率 | 四球率 | 三振率 |
|---|---:|---:|---:|
| 平均打者×平均投手 | 3.105% | 8.409% | 23.105% |
| 強打者×平均投手 | 4.413% | 11.643% | 14.906% |
| 平均打者×強投手 | 2.166% | 5.923% | 32.339% |
| 強打者×強投手 | 3.219% | 8.481% | 22.149% |
| 疲労した打者×平均投手 | 2.633% | 7.509% | 26.544% |
| 平均打者×疲労した投手 | 3.467% | 9.688% | 19.960% |
| 若手・同じ能力と健康 | 3.105% | 8.409% | 23.105% |
| ベテラン・同じ能力と健康 | 3.105% | 8.409% | 23.105% |

同じ強打者でも投手が強ければ成績分布が変わります。若手・ベテランは能力と健康を固定すると同じ確率で、年齢だけの一律ボーナスは加えません。年齢は成長・衰退・回復の過程で効きます。短期には強打者が不振になることもあり、成功を保証する処理はありません。[全確率・抽選件数](../../data_sources/stage11/ability_contrasts.json)

平均能力0・疲労0なら元の確率と完全一致。アダプターを無効にすると、同じ第10段階の名簿・日付・シードについて、試合ID・結果・全ジャーナルの一致もテストしています。基礎の0確率を正に変えず、未対応経路を増やしません。

能力は完全独立ではなく、弱い共有因子と小さな相反因子を持ちます。生成集団のコンタクト×長打の相関は0.271、奪三振×制球は0.161、スタミナ×先発適性は0.313でした。個々の相反因子があっても集団全体の相関が負になるとは限りません。これは実測の相関推定ではありません。

## 7. 公開情報と内部情報・履歴

内部の真値・才能・成長パラメータ・試合前入力・ルート鍵を持つSQLiteは、ローカルの管理者用に保存します。**公開ZIP・GitHubの公開データへ入れていません。** 公開APIは評価とその誤差、年齢・役割・健康状態、完了シーズンの成績だけを返します。余分な内部フィールドは拒否し、APIオブジェクト自体も内部DBや世界への参照を持ちません。

研究用の固定シードは再現用に公開しており、研究世界は再構築できます。本番の秘密を保証する鍵ではありません。運営時は別の非公開鍵を使う必要があります。ローカルデモは鍵の指定がなければ新しい256bit鍵を作ります。Web認証・本格権限サービスの完成を意味しません。

試合・試合前入力・負荷・健康更新を1トランザクションで確定し、更新削除を拒否します。キャリアは更新後状態とハッシュ連鎖で復元し、成長や故障を再抽選しません。過去日には当時の評価だけを返し、まだ起きていない新規選手や未来の評価を混入させません。シーズン途中の公開成績APIは今回未実装で、公開統計は完了済みシーズンに限定しています。
